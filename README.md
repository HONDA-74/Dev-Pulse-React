# 📌 Overview

DevPulse is a modern developer blogging platform where users can create, explore, and interact with technical posts in a clean and responsive environment.

The project was built to practice advanced frontend development concepts using React ecosystem tools and modern architecture patterns.

It focuses on:

* Scalability
* Reusability
* State Management
* User Experience
* Clean Code Structure

---

# ✨ Features

## 🔐 Authentication System

* User Registration
* User Login
* Persistent Authentication using localStorage
* Protected Routes

## 📝 Posts Management

* Create New Posts
* Browse All Posts
* Post Details Page
* Real-time Search

## 👍 Reactions System

* Like Posts
* Dislike Posts
* Toggle Reactions
* Prevent duplicate reactions per user

## 🌍 Internationalization (i18n)

* English Language Support
* Arabic Language Support
* RTL / LTR Switching

## 🌙 Theme System

* Dark Mode
* Light Mode
* Theme Persistence

## 🎨 Modern UI/UX

* Fully Responsive Design
* Smooth Transitions & Animations
* Clean Minimal Interface
* Reusable Components

# ⚙️ Installation & Setup

## 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/devpulse.git
```

---

## 2️⃣ Navigate into the project folder

```bash
cd devpulse
```

---

## 3️⃣ Install dependencies

```bash
npm install
```

---

## 4️⃣ Run the React application

```bash
npm run dev
```

---

## 5️⃣ Start JSON Server

```bash
npx json-server --watch db.json --port 4000
```

# 🔥 Main Functionalities Explained

## 🔐 Authentication

Users can:

* Register an account

* Stay logged in after refreshing
* Access protected pages only when authenticated

---

## 📝 Posts

* Browse technical content
* Open detailed post pages

Users can switch between:

* Light Theme
